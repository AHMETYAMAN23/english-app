# İngilizce Öğren

Kapsamlı İngilizce öğrenme platformu. Gramer, kelime, okuma parçaları ve quizler.

## Kurulum

```bash
npm install
npm run dev
```

## Vercel'e Yükleme

1. Bu klasörü GitHub'a yükleyin
2. https://vercel.com adresine gidin
3. "Add New Project" → GitHub repo'nuzu seçin
4. "Deploy" butonuna basın

Vercel otomatik olarak Vite projesini algılar ve yayına alır.
